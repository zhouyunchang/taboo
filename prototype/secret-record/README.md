# 密钥记录 · 高保真交互原型

> 2026-11-13 确认稿已落地到真实应用：`apps/web/src/pages/SecretRecord.tsx` 与 `components/SecretRotation.tsx`、`SecretCompare.tsx`、`SecretTraces.tsx`。本目录保留为对照原型；真实页面的长度/对比数字只在显式读取后出现，不沿用原型里的合成长度。

这是 taboo 控制台「密钥详情」重做方向的独立可交互原型，不连接真实 API，数据全部为合成演示数据。

打开方式（任选其一）：

```bash
# 在本目录
python3 -m http.server 7200 --bind 127.0.0.1
# → http://127.0.0.1:7200/
```

## 为什么要改

现在抽屉把所有东西压进 560px 的一列：值、档案、版本、对比、轮换表单相互叠在一起。原型把「一枚密钥」拆成两个角色：

- **左叶：封印与档案。** 值、显示/复制、位置、标签、备注、轮换状态一行、删除。它是这把密钥的身份，始终只有一件事。
- **右叶：留痕。** 「版本 / 轮换 / 痕迹」三章，一次只读一章：
  - 版本：时间线、当前版、对比、回滚；下方「最近读取」把谁刚看过放到版本旁边。
  - 轮换：策略摘要、下次时间、负责人、轮次列表、策略表单；没有策略时给一条能照做的空态。
  - 痕迹：只属于这把密钥的审计记录，可筛选、可加载更早的记录。
- 对比不再是常驻表单，而是版本章里的一个子页：两个选择器、整值/逐行对照、默认掩码、主动显示明文。

这样「轮换策略」不再和「版本历史」挤在同一条滚动里；敏感动作（回滚、删除、标记固定）各有自己的确认回执；审计从组织页的下钻变成记录本身的一部分。

## 可以试的交互

- 显示明文 / 隐藏、复制（会追加一条显示痕迹，并更新「最近读取」）；失焦自动收回。
- 版本：对比版本、行内「对比」「回滚到此」、只有一个版本时的教学空态。
- 对比：交换基准、选择相同版本会自动调整另一侧、显示明文后看字符级差异。
- 轮换：暂停/恢复、编辑策略（改动间隔会实时更新预览）、立即运行、轮次详情、完成本轮、标记固定与「改为轮换」、删除策略后的空态、重新设置。
- 痕迹：全部/显示/写入/轮换筛选、加载更早的记录、按天分组。
- 编辑：新值不预填当前明文；保存产生新版本；删除密钥要输入 Key 才可确认。
- 桌面：左侧印台「密钥」可回到列表；浏览器后退也可返回。
- 手机：页头收成「返回 / 标题＋编辑」两行；章节栏吸顶；底部「密钥」回到列表；版本、轮换、对比各有一套窄屏布局。

## 文件

- `index.html` — 页面骨架与所有弹窗/章节容器
- `record.css` — 卷宗页新增的结构与响应式规则
- `base.css` — 从 `apps/web/src/styles.css` 复制的令牌与基础组件（原型内使用；实现时仍以仓库里的 `styles.css` 为唯一主题源）
- `app.js` — 合成数据、渲染、交互；无构建步骤
- `shots/` — 桌面与手机截图

## 实现到 `apps/web` 时的注意

- 这是独立页面原型，**没有改动**真实应用。实现时应把 `SecretDetail.tsx` 的抽屉替换为记录页，保留现有原生 `<dialog>`、Escape、焦点归还、焦点可见与 `role=alert/status` 语义。
- 档案里的「轮换」一行只做摘要；完整策略在轮换章。不要把策略表单重新塞回左栏。
- 对比与痕迹都读敏感/历史数据：默认掩码、显示明文只在内存、失焦收回；服务端仍是唯一鉴权事实源。
- 每把密钥的痕迹可用现有审计接口的 `resource=project/<slug>/secret/<key>` 过滤；进入痕迹章时再拉取并分页，不要随记录页首屏加载。
- 版本接口目前只有 `created_by` id 与时间；若要把「写入者」显示成姓名，需要在服务端补一个映射。原型按现有契约展示 id。
- 编辑表单不要预填当前明文；复制要按产品语义进入审计（原型在未显示时复制会加一条「显示」痕迹）。
- 手机底栏「密钥」在记录页应回到列表，否则长页没有常驻出口。
- 原型里「复制后 20 秒清空剪贴板」保留为界面回执，没有真的定时清空系统剪贴板；真实实现沿用 `apps/web` 的现有行为。

所有姓名、密钥、时间、轮次数值均为合成演示数据，不代表真实客户或真实密钥。
