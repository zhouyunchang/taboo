# taboo v1.0.0 发布说明

**开源自部署密钥管理平台首个正式版本。** 单二进制（前端 embed + SQLite 内嵌）即可投产，
覆盖密钥全生命周期：写入 → 版本 → 回滚 → 读取（reveal 分离 + 审计）→ 同步外传。

## 功能全景

### 密钥核心（M1–M2）
- Go 重写后端：Chi 模块化单体 + 单二进制 embed.FS（`#1`）
- 密码哈希 Argon2id，scrypt 透明迁移（`#2`）
- 机器身份 client_credentials + 显式 scope（`#3`）；TOTP 2FA + 恢复码（`#4`）
- 多级文件夹物化路径（`#5`）
- 密钥 CRUD + 版本历史 + 回滚 + .env 导出；key/folder 分离杜绝 %2F 路由缺陷（`#16`）

### 生态接入（M3–M4）
- OpenAPI 3.1 契约唯一事实源 + 类型生成 + 路由漂移检查（`#7`）
- Go SDK / CLI（`login run get set export`）/ 151 规则泄漏扫描 pre-commit（`#6` `#8`）
- MCP Server：AI Agent 只读密钥访问，scope 受限 + 全审计（`#10`）
- 动态密钥：PostgreSQL 短期账号 lease，到期自动 DROP（`#9`）

### M5：生态与发布（本里程碑）
- **Secret Sync**（`#11`）：密钥变更单向推送 GitHub Actions Secrets（repo/environment 两级，
  libsodium sealed box）/ Vercel env（按 target 区分）/ Cloudflare Workers secrets；
  事件驱动 + 手动全量重推；指数退避 + 死信；同步记录只存 sha256 指纹
- **Webhooks**（`#12`）：密钥创建/更新/回滚/删除事件广播；HMAC-SHA256 签名
  （`X-Taboo-Signature: t,v1`，时间戳窗口防重放）；至少一次 + 退避重试 + 投递日志；
  负载不含明文
- **OIDC SSO**（`#13`）：组织级多 IdP；discovery + JWKS(RS256) 验签；
  JIT 入组（claim → 角色映射，默认 viewer）；与密码/2FA 共存（IdP 视为二次校验）
- **审计与发布**（`#14`）：审计导出 CSV/JSONL（筛选 + 异步任务 + 下载链接，导出留痕）；
  多阶段 Dockerfile + compose；Helm Chart（K8s Secret 注入 master key）；
  GoReleaser 流水线（SBOM + cosign 签名）；`--check` 启动自检

## 升级与兼容

- 首次发布，无升级路径问题
- 数据目录 `$TABOO_DATA_DIR` 兼容 Node MVP 的 SQLite schema（自动迁移）

## 已知限制（v1.0）

- SQLite 单写者：单副本部署；HA 需等待 PG 主模式（issue #1）
- Secret Sync 删除事件不外传（目标平台删除语义不可靠），需手动清理
- 审批流与访问请求为 v2 规划（issue #15）
